# M-105 盟友：中甲穿透 + 双倍弹药 + 双倍射速

- 穿甲：轻甲 AP2 → 中甲 AP3
- 弹匣容量：250 → 500
- 初始备用弹匣：2 → 4
- 备用弹匣上限：3 → 6
- 三档射速：700 / 850 / 1150 → 1400 / 1700 / 2300 RPM

游戏内显示的低穿甲标签不会更新，这是 UI 文案，不影响实际穿甲。

## 依赖

**只需要 Bingus Shared Loader v15 及以上**（或兼容的新版本）。

无需其他前置，下载即用。

## 安装

导入本包到 Arsenal / HD2 Mod Manager，启用后部署，彻底退出游戏再重新启动。Loader 放到列表最后（若开启「首个 mod 优先」则放最前）。改动只影响重启后新呼叫的盟友。

## 版本与适配

- 适配游戏构建 **25327279**。
- 运行时受保护写入与回读已通过，用户已实测确认生效。
